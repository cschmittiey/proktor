# Traktor broadcast

**Preferences → Broadcasting**

| | |
|---|---|
| **Server** | `<proktor IP>` |
| **Port** | `8000` |
| **Mount** | `/live` |
| **Password** | `traktor` |
| **Format** | Ogg Vorbis, 192 kbps |
| **Stream name** | your DJ name |

Then hit the **antenna** button in the Mixer/Master panel.

## Troubleshooting

- **Antenna blinking** means it can't connect. Check the server IP, port and password above.
- **"mountpoint in use"** means the previous DJ is still connected. Ask the booth.
- **Wrong track on the screen** means it's on a delay. Tell the booth, or use the control page.
